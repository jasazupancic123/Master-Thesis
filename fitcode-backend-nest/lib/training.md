# Expressions

- `ALL_PARAM_VALUES`, `all param values` refers to parameter values of exercise (inherited by its main component) where all hardcoded params (_volWorkSets_, _volWork1_, _volWork2_, _intWork1_, _intWork2_, _volRec1_, _intRec1_) are populated with pre-defined values. This can be for prescribed exercises and for completed exercises. See `src/training/constant/all-param-values.constant.ts` to see the constant.

- `PARTIAL_PARAM_VALUES`, `partial param values` refers to parameter values of exercise where only a few hardcoded params are populated with pre-defined values (_volWorkSets_, _volWork1_, _intWork1_).
